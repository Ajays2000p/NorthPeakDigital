# NorthPeak Digital

A simple, modern static website for NorthPeak Digital built with HTML, CSS, and JavaScript.

## Description

This project is a clean landing page showcasing digital services, pricing plans, client testimonials, and a contact form. It uses a sticky navigation bar, smooth scrolling, responsive layout, and interactive mobile navigation.

## Features

- Sticky navigation bar with smooth anchor scrolling
- Responsive hero, services, testimonials, pricing, and contact sections
- Mobile-friendly hamburger menu
- Pricing CTA buttons that navigate to the contact section
- Contact form with client-side validation and success feedback

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Structure

NorthPeakDigital/
│── index.html
│── styles.css
│── script.js
│── README.md

## Installation

1. Clone or download the project files.
2. Open `index.html` in a web browser.

## Usage

- Use the navigation links to jump between sections.
- Click pricing buttons to scroll to the contact section.
- Fill out the contact form and submit to see the success message.
